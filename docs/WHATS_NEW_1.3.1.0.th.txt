มีอะไรใหม่ใน BetterNote 1.3.1.0

• ปรับการใช้หน่วยความจำเมื่อเปิดสมุด รูปภาพ และ PDF ขนาดใหญ่ โดยโหลดหน้าและภาพความละเอียดสูงเมื่อจำเป็น
• ปรับการแสดงลายเส้นและการจัดคิวงานเบื้องหลัง เพื่อให้เขียนได้ต่อเนื่องขึ้น
• แก้ลายเส้น PDF ที่ส่งออกแตกลายงาหรือเห็นรอยต่อเป็นปล้องเมื่อเปิดด้วย Microsoft Edge
• ใช้ PDF ของหน้าที่ยังไม่เปลี่ยนซ้ำระหว่างเตรียม Backup ลดการสร้างใหม่หลังแก้งานเพียงบางหน้า
• ปรับการคืนทรัพยากรเมื่อยกเลิกนำเข้าและส่งออก PDF
• แก้ข้อความ “Object has been destroyed” ตอนปิดแอป และปรับการปิดจากหน้าต่างที่ย่อหรือซ่อน โดยยังรอเซฟงานในเครื่องให้เสร็จ
• ปรับการกด Export Options และปุ่มปิดด้วย Surface Pen พร้อมจัดป๊อปอัปให้อยู่ในหน้าต่างแม้เปิดใกล้ขอบจอ
• เพิ่มภาษาสเปน เยอรมัน และอาหรับ (รุ่นทดสอบ) พร้อมเนื้อหาคู่มือที่แปลแล้ว
• ขยายหน้าต่างตั้งค่า และเพิ่มลิงก์ดาวน์โหลดรุ่นเก่ากับช่องทางเสนอแนะ

ภาษาอาหรับยังเป็นรุ่นทดสอบ รุ่นนี้ยังใช้รูปแบบสมุดและไฟล์สำรองเดิม
