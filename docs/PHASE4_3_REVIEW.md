สถานะ: ตรวจอัตโนมัติผ่าน ผู้ใช้รายงานว่าส่วนอื่นผ่านแล้วและขอแก้เฉพาะมุมเรขาคณิตที่มน รอบนี้แก้มุมและตรวจซ้ำแล้ว ยังรอผู้ใช้ลองมุมรูปทรงใหม่ ไม่ได้ระบุว่าทดสอบด้วยฮาร์ดแวร์ชนิดใด ไม่มีการ commit/push รอบนี้

## สิ่งที่แก้และเหตุผล

1. CanvasBoard เรียก snapAngle แต่ไม่ได้ import ทำให้เครื่องมือเส้นตรงเกิด ReferenceError ทั้งตอน preview และจบเส้น เพิ่ม import จาก utility ที่มีอยู่เดิม ก่อนแก้ชุดทดสอบหยุดตั้งแต่กรณีแรกที่เส้นตรงไม่แสดง preview
2. snapAngle เดิมเลือกเป้าหมายแรกที่อยู่ในระยะ ทำให้ช่วงมุมที่ซ้อนกันเลือกมุมที่ไกลกว่า เช่น 37.8 องศาถูกจัดเป็น 30 แทน 45 องศา ตอนนี้เลือกเป้าหมายที่ใกล้ที่สุดภายในช่วงเดิม เกณฑ์ความตรงและการจับรูปทรงอื่นยังใช้เดิม
3. Preview เดิมวาดเส้น/รูปทรงโดยตรง แต่หลังบันทึกใช้จุดปากกาและ nib renderer คนละทาง รวมถึงขนาดหัวลูกศรต่างกัน ตอนนี้ preview ใช้จุดและการตั้งค่าเดียวกับรอยบันทึก ร่วมใช้ renderer เดียวกันทั้งตอนลากและหลังบันทึก โดยรักษาการแสดงรอยเก่าที่ไม่มี metadata
4. เครื่องมือรูปทรงรวม preview หลาย pointermove ในหนึ่งเฟรมเป็นการวาดครั้งเดียวด้วยรูปทรงล่าสุด ปล่อย/ยกเลิก/ถอด Canvas ยกเลิกงานค้างผ่านทางเดิมของ 4.2
5. รูปที่ Draw & Hold แปลงแล้วรับพิกัดปล่อยปากกาจริง แม้ไม่มี pointermove สุดท้าย ร่วมใช้ฟังก์ชันอัปเดต geometry เดียวกับการลาก
6. วงกลม/วงรีตอนลากปรับขนาดอัปเดต center ตามกรอบใหม่ คงรูปร่างที่จับได้เมื่อปล่อยตรง hold point เดิม และข้ามความต่างพิกัดต่ำกว่า 1e-6 ที่เกิดจากทศนิยม ไม่ใช้จุดปลอมจาก blur/cancel
7. เปลี่ยนชนิดรูปทรงระหว่างลากใช้การจบแบบขัดจังหวะ ยกเลิกภาพที่ยังลากไม่เสร็จและคืนล็อก แทนการบันทึกเป็นรูปทรงอีกชนิด
8. ตามผลลองของผู้ใช้: รูปเรขาคณิตมุมมนเพราะใช้ quadratic smoothing ของลายมือ เพิ่ม shapeType เฉพาะรูปทรงที่สร้างใหม่ ให้รูปเหลี่ยม เส้นตรง ลูกศรและเส้นหักมุมใช้ lineTo/miter join และปลาย butt ใน renderer ร่วม จำกัด miterLimit 10 กันยอดยาวเกิน วงกลม/วงรี ลายมือ ไฮไลต์และรอยเก่าที่ไม่มี metadata ใช้ทางเดิม ไม่เดาชนิดรูปจากลายมือเก่า
9. ปิด path เฉพาะเมื่อจุดต้น/ท้ายตรงกัน ชิ้นที่ถูกลบแยกแล้วไม่เชื่อมช่องที่ลบกลับ ตรวจ move/recolor/precision erase และ metadata หลัง Undo/Redo/เปิดใหม่ทั้งสมุดและ Whiteboard

ไม่มี worker หรือ I/O ใหม่ใน pointermove ไม่เพิ่มเครื่องมือรูปทรงให้ไฮไลต์ ไฮไลต์ลากค้างยังแปลงได้เฉพาะเส้นตรง ไม่เปลี่ยนระบบ gesture, backup, OAuth, คิวเซฟ หรือรูปแบบฐานข้อมูล

## ผลลองของผู้ใช้และสิ่งที่ต้องตรวจรอบมุมคม

ผู้ใช้แจ้ง “นอกนั้นผ่านหมด” และให้แก้เฉพาะมุมเรขาคณิต จึงไม่ขอให้ลองขั้นตอนเดิมซ้ำ รอบนี้ให้ปิดแล้วเปิดตัวทดสอบจากโค้ดล่าสุด วาดสี่เหลี่ยมหรือสามเหลี่ยมใหม่ ตรวจมุมหลังปล่อยและหลังเปิดสมุดใหม่ รูปเดิมที่สร้างก่อนมี shapeType ยังคงหน้าตาเดิมเพื่อไม่เปลี่ยนลายมือเก่า

ก่อนแก้ regression พิกเซลพบมุมสี่เหลี่ยมสามมุมไม่มีสี [0,0,0,255] หลังแก้ทุกมุมที่ตรวจมีสี ทั้ง preview และภาพบันทึกตรงกัน ตรวจ renderer พิกเซลทั้ง Browser/Electron DPR 2 และภาพ PDF แล้ว รายงานชุดล่าสุดอยู่ใน scratch/phase43-qa/corners-*.log (Git ignored)

## ขั้นตอนตรวจเดิมสำหรับอ้างอิง

1. ใช้ตัวทดสอบจากโค้ดล่าสุด เลือกเครื่องมือรูปทรงทั้ง 5 แบบ ลากไปข้างหน้า/ย้อนกลับ และลองซูม ภาพหลังปล่อยควรตรงกับภาพที่เห็นขณะลาก
2. ใช้ปากกาวาดเส้นหรือวงกลมแล้วค้างประมาณครึ่งวินาที ลองปล่อยอยู่ที่เดิมและลากเปลี่ยนขนาดก่อนปล่อย ตรวจว่ารูปไม่กระโดดหรือเปลี่ยนขนาดเอง ไฮไลต์ค้างยังได้เฉพาะเส้นตรง
3. ลอง Undo/Redo และออกจากสมุดแล้วเปิดใหม่ ทั้งสมุดธรรมดาและ Whiteboard ตรวจว่ารูปอยู่ตำแหน่งเดิมครบ

หากยังเปิดโปรเซสเก่า ให้ปิดและเปิดตัวทดสอบใหม่จาก workspace เพื่อให้ใช้ dist ที่ build ล่าสุด ไม่ถือว่าตัวติดตั้ง BetterNote ที่ลงไว้เดิมได้รับการอัปเดตแล้ว

ยังไม่รับรองว่าไม่มีบั๊กหรือไม่หน่วงทุกอุปกรณ์ เฟส 4.4 เรื่องท่าทางสัมผัส/เลื่อนหน้า และงานหน่วยความจำเฟส 5 ยังต้องทำตามแผน
